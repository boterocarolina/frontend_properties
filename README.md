# 📋 Lista de Tareas con Procesos

Aplicación para **gestionar listas, tareas y procesos** de manera sencilla y organizada, desarrollada con tecnologías modernas de Frontend.



## 🚀 Tecnologías Usadas

| Tecnología   | Descripción |
| ------------ | ----------- |
| 🛠️ **React** | Librería para construir interfaces de usuario reactivas y modulares. |
| 🎨 **Tailwind CSS** | Framework de estilos utilitario para diseño responsivo y moderno. |
| 🔄 **Context API** | Manejo del estado global para compartir datos entre componentes. |
| ⚡ **Vite** | Empaquetador rápido para desarrollo y construcción de aplicaciones. |



## 🧩 Funcionalidades Principales

- 📄 Crear nuevas listas de tareas.
- ✅ Agregar tareas dentro de las listas.
- 🛠️ Editar tareas para incluir múltiples procesos.
- 📝 Marcar procesos como completados (checklist).
- 📱 Interfaz adaptada a móviles y escritorios.
- 📂 Organización en tarjetas responsivas (1 en móviles, 3 en escritorio).



## 🛠️ Pasos para Usar la Aplicación


### 🥇 Paso 1: Agregar Nueva Propiedad
- Haz clic en el botón **"+ Nueva Propiedad"** en el menú lateral.
- Ingresa el **Nombre de la nueva Propiedad**.
- Ingresa la **Descripción de la nueva Propiedad**.
- Presiona **"Crear Lista"**.

### 🥈 Paso 2: Ingresar a la Lista Creada
- Desde el menú lateral, selecciona la lista que acabas de crear.


### 🥉 Paso 3: Agregar una Tarea a la Lista
- Dentro de la lista seleccionada, haz clic en **"+ Agregar una tarea"**.
- Escribe el **nombre de la tarea**.
- Presiona **"Agregar"**.

### 🏆 Paso 4: Checklist de Procesos
- Cada tarea creado tiene una **casilla de verificación**.
- Marca la casilla cuando completes el proceso ✅.


## 📱 Diseño Responsivo

| Dispositivo | Comportamiento |
| :--------- | :-------------- |
| 📱 **Móvil** | Se muestra las tarjetas de tareas por fila. El menú lateral se desplaza desde la izquierda y se cierra al hacer clic fuera. |
| 🖥️ **Escritorio** | Se muestran las tareas por fila. El menú lateral está siempre visible. |
